# 组会速览：3D 几何前端已经做到哪一步

## 一句话

我们已经在 RTX 4060 Laptop 上跑通“RGB → 轻量几何 → GPU 重投影”，但还没有证明加上几何后，真实游戏生成比 Copy 复用更快、更好。

## 可以汇报的三个结果

1. **不需要先优化在线 3DGS。** MoGe-2 单张 RGB 可以输出点图/深度/内参；本地约 59 ms，需要低频摊销。
2. **重投影实现可以很便宜。** 同一 GTA 任务从 NumPy 212.207 ms 降为 CUDA 3.693 ms；约 57.46× 仅指该组件。
3. **画质揭示了强基线。** 官方展示视频 59 个有效帧对中，两个短轨迹的平均 Copy PSNR 都高于固定 Warp，说明不能把几何覆盖率直接当作可复用率。

## 本次审计的新增发现

Gap8 转向裁剪，Copy 的 RGB tile 阈值通过率为 85.044%；真正“每块选 Copy/Warp”的离线 Oracle 为 85.680%，只多约 0.64 个百分点。旧 87.566% 是逐像素混选，不能当作同一个算法。原 7.22× 也不是实测，而是低 active-Q 区间的乐观外推。

## 下一步怎么分工

- 几何侧：准备干净 source/target + action/pose；做边界友好 splat、动态/HUD 分离、多 anchor 选择。
- 路由侧：只用历史信息预测 `Copy/Warp/Neither`，评估误放行而不只看均值。
- 生成侧：在服务器上量真实 AR-DiT 的 dense/bypass/packed Q 延迟，把 VAE、KV、路由和显示一起记账。

## 回答“速度收益为正了吗？”

**组件级是：CUDA Warp 相对原 CPU 实现收益明确。系统级还不能下结论：真实 AR-DiT 未接入；当前假设账本中，几何分支仍未超过强 Copy 基线。**
